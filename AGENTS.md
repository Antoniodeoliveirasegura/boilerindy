# Instructions for coding agents

[`CLAUDE.md`](CLAUDE.md) is the source of truth for working in this
repository: the layout, where a change goes, the workflow and the conventions.
It is written for every coding agent, not only Claude Code, so read it in full
before your first edit. This file is for the agents that load `AGENTS.md` and
not `CLAUDE.md` (Codex, Cursor, Copilot and others), and repeats only the hard
rules. If the two ever disagree, `CLAUDE.md` wins, and the README and CI win
over both.

## Hard rules

- **No em dash (U+2014) or en dash (U+2013)** anywhere: code, comments, docs,
  UI copy, commit messages and PR descriptions. Use a hyphen, a comma or a
  colon.
- **No AI credit** in a commit message or a PR description: no
  `Co-Authored-By` trailer that names an assistant, no "Generated with" or
  "Generated by" footer, no `claude.ai/code` session link (a `Claude-Session:`
  trailer included). If your tool adds these by default, turn its attribution
  off. Crediting a person is fine.
- **pnpm only**, never `npm install` or `yarn`. The frontend has its own
  lockfile, so install twice: `pnpm install --frozen-lockfile` at the root,
  then the same inside `boilerindy-react/`. The root install also turns on the
  git hooks in `.githooks/`, which run the dash and credit checks on every
  commit.
- **PRs go to `develop`.** Branch from `develop` and open the PR against it;
  `main` only receives release PRs from `develop`. Do not merge: the owner
  merges.

## CI mirror

Run these from the repository root before you open a PR, and have every one
green:

```bash
pnpm test:backend
pnpm -C boilerindy-react run lint
pnpm -C boilerindy-react run typecheck
pnpm -C boilerindy-react test
pnpm -C boilerindy-react run build
pnpm exec playwright test
pnpm run check:conventions
```

Install Chromium once with `pnpm exec playwright install chromium` before the
first Playwright run. CI also scans the PR description; check yours before you
post it with `PR_BODY="$(cat body.md)" node scripts/check-conventions.mjs pr-body`.
