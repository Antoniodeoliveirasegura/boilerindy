# BoilerIndy website

BoilerIndy (https://www.boilerindy.app) is a free campus app for Purdue University Indianapolis students: classes, dining, the JAGLINE campus shuttle, events and a campus board in one place. Test runs use the live site and its production backend, so every action reaches real data.

Rules for every run:

- Stay signed out. Never create an account, never continue with Google, and never sign in with a real address.
- Never request a password reset or any other email.
- A signed-out visitor can use the landing page, the live dining, bus, map and free food previews, the install guide, the sign-in page and the legal pages. Other pages ask them to sign in.

Terms: Tower Dining is the campus dining hall. JAGLINE is the campus shuttle.
